# Code Review

## Scope

Read `003.md` at task start. This skill is task-specific and local-only. Do not activate remote integrations, persistent modes, hooks or unrelated implementation.

## Workflow

1. Fix the local baseline and inspect the diff plus supplied spec/acceptance criteria.
2. Run one standards pass using actual project checks and documented judgment rules.
3. Run a separate specification pass; keep findings logically independent, with authorized delegates only if available.
4. Report actionable findings with location, impact and evidence. Apply changes only if the user requested them.

## Default output

Standards/spec findings, validation actually run and review-independence limitations.

## Failure boundary

Report the missing input or capability; do not fabricate evidence or broaden the task.
